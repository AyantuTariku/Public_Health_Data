# GitHub Assignment

## Overview

This project uses Python to display public health records and demonstrates basic Git and GitHub operations, including version control and commits.

## Project Files

- `sample_data.py`: Python code that displays public health records.
- `README.md`: Project description and instructions.

## Data Fields

Each record contains:

- ID
- Age
- Disease
- Region

## Diseases Included

- Malaria
- Tuberculosis
- HIV

## Requirements

- Git
- Python 3

## How to Run

**Option 1: Python IDLE**

1. Open `sample_data.py` in Python IDLE.
2. Select **Run → Run Module**.
3. View the records in the Python Shell.

**Option 2: Terminal**

Run the following command:

```bash
python sample_data.py
```

## Purpose

This project provides practice in Python programming, creating a Git repository, tracking changes, saving commits, and publishing files on GitHub.

The records are illustrative and intended for educational purposes only.
