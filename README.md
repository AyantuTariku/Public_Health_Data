# GitHub Assignment

## Overview

This project uses Python to display sample public health records and demonstrates basic Git and GitHub operations.

## Project Files

- `sample_data.py`: Python script that displays public health data.
- `README.md`: Project description and instructions.

## How to Run

**Using Python IDLE**

1. Open `sample_data.py` in Python IDLE.
2. Select **Run → Run Module**.
3. View the output in the Python Shell.

**Using the Terminal**

```bash
python sample_data.py
```

## Data Note

The records are illustrative and intended for educational purposes only.
