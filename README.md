# Public Health Data

## Overview
This project uses Python to display public health records.

## Data Fields
Each record contains:
- ID
- Age
- Disease
- Region

## Diseases Included
- Malaria
- Tuberculosis
- HIV

## How to Run
1. Open `sample_data.py` in Python IDLE.
2. Select **Run → Run Module**.
3. View the records in the Python Shell.

## Files
- `sample_data.py`: Python code that displays the public health records.
- `README.md`: Project description and instructions.
